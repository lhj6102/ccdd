# v0.2.0 검증

2026-09-05, Node.js 24.15.0과 Codex CLI 0.153.4에서 확인했다.

- 실제 `doctor`가 `gpt-6-astra`·`medium` 설정으로 응답을 받고, Artifact MCP에서 임의 진단 값을 읽은 호출을 확인해 READY를 반환했다. 동일한 두 Agent Profile은 한 번의 호출로 진단했다.
- 잘못된 Codex 실행 경로를 지정한 Agent 진단은 `PROVIDER_NOT_EXECUTABLE`과 NOT_READY, 종료 코드 1을 반환했다.
- 같은 잘못된 Codex 경로에서도 Runtime Critic만 선택한 진단은 READY, 종료 코드 0을 반환했다. 프로젝트 테스트는 실행하지 않았다.
- 실제 `tests-spec` Agent Critic만 실행해 GREEN과 종료 코드 0을 받았다. Run에는 요청 1개, `scope.kind=critic`, `predecessorId=null`이 기록됐다. Spec·Tests Viewer 호출 근거를 확인했다.
- 실제 브라우저에서 Runtime Critic만 실행한 GREEN·RED, 제외된 Critic 표시, 수동 준비 진단, 이력·새로고침 범위 복원을 검증했다. 자동 폴링은 진단을 재호출하지 않았고 브라우저 오류는 없었다.
- 자동 검증 51개가 통과했다. 인증·모델·네트워크·MCP 오류와 위조된 진단 응답의 실패 처리, 진단 정리, 선택 범위, 반복 스냅샷, 완료 대기·종료 코드 및 npm bin 링크 진입점을 포함한다. 자동 검증의 Provider 대역과 위 실제 계정 검증은 구분했다.

- 별도 npm 설치본의 `ccdd` 링크로 도움말과 Runtime READY·누락된 Codex NOT_READY를 확인했다. 진단용 worktree는 정리됐으며 인증·실행 상태는 패키지에 포함되지 않았다.
