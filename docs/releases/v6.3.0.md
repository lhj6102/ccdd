# CCDD 6.3.0 — Pi 0.99.1 and new model profiles

Pi AI and Pi Agent Core are updated from 0.87.1 to 0.99.1. Pi's breaking changes
in that range only remove and rename its image-model API, which CCDD does not use,
so no CCDD source changes were needed.

## New model profiles

| Provider | Model | Reasoning levels |
| --- | --- | --- |
| `openai-codex` | `gpt-6.1-sol` | `minimal`, `low`, `medium`, `high`, `xhigh`, `max` |
| `anthropic` | `claude-sonnet-5-5` | `low`, `medium`, `high`, `xhigh`, `max` |

`gpt-6-luna` remains available with `max`. CCDD still resolves the exact requested
model and level: Sonnet 5.5 rejects `off` and `minimal` instead of mapping them.

## Anthropic authentication

No new option is added. Provide an `anthropic` `api_key` or `oauth` entry in an
external Pi auth file passed with `--pi-auth-file` (or `CCDD_PI_AUTH_FILE`), or set
`ANTHROPIC_API_KEY`, `ANTHROPIC_OAUTH_TOKEN` or `ANTHROPIC_AUTH_TOKEN`. Create an
OAuth entry yourself with `npx @earendil-works/pi-ai@0.99.1 login anthropic`, then
keep the file outside the reviewed workspace. CCDD's credential store stays
read-only and rejects OAuth tokens expiring within five minutes.

## Identity

Package versions never enter review identities. A golden test pins the Critic
hash and request key of a fixed project with both new models, recorded under Pi
0.87.1 and unchanged under 0.99.1, so this update does not force re-reviews.

Four packages are aligned at 6.3.0 with the existing core peer floor unchanged.
