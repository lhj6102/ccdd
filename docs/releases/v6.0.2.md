# CCDD 6.0.2 — Current installation guides

This documentation-only patch aligns all three package versions at 6.0.2 and
corrects installation instructions that still selected the version 4 packages.
The root README, getting-started guide and npm package READMEs now use matching
current versions. The release guide points to this patch.

## Installation choices

Install core and Project together for definitions, the CLI and review runtime.
Install default-tools explicitly when using its common view scripts; Project
does not install that optional package. The getting-started guide explains
transitive dependencies, non-optional core peers, automatic peer installation
and why explicitly declaring matching packages is the predictable choice.
Installing a tool package does not register views in a project.

Introductory dependency-gate wording now reflects existing behavior: dependency
Critics outside the same SCC need current GREEN evidence, while SCC peers may
execute together after external gates pass. This is a documentation correction,
not a scheduling change.

## Unchanged runtime and evidence

No runtime code, dependency ranges, identity rules, reuse rules or state format
changes. Existing format-6 state remains valid, and this patch introduces no
identity salt or forced review invalidation. Normal input-change rules still
apply when reviewed material itself changes. Node.js support remains 22 LTS
(22.19.0 or later); Project and default-tools retain the core peer range
`>=6.0.0 <7`.

This patch does not implement [the pending 6.1 work](https://github.com/lhj6102/ccdd/issues/63)
and does not add a single-package umbrella or bundled distribution. Upgrades
from before 6.0 still require the [6.0 migration](../migration-v6.md).
