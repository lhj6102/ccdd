# CCDD v3.1.2

CCDD 3.1.2 fixes Windows image results and makes tool failures and Human Claim
preparation easier to diagnose. All three packages release together:
`@ccdd/core`, `@ccdd/project`, and `@ccdd/default-tools`.

## Changes

- Accept nested image output paths on Windows while retaining traversal and
  symlink checks.
- Report tool-check failure stages, safe codes/messages, and the allocated output
  directory, including when returned images or other content are rejected.
- Show Human Claim preparation phases, elapsed time, heartbeat, scan progress,
  phase timings, and attempt status. Existing fixed-input checks remain intact.
- Keep delayed status refreshes from cancelling a valid Claim retry. Polling
  remains observational; closing the review view cancels its pending requests.

## Install and upgrade

```sh
npm install --ignore-scripts @ccdd/core@3.1.2 @ccdd/project@3.1.2 @ccdd/default-tools@3.1.2
```

Node.js 22 LTS (22.19.0 or later) is required. The default-tools package is
optional when all tools are custom. Existing 3.x configurations and stored
review evidence remain compatible. Restart an active monitor with the upgraded
CLI to use the new preparation display.

## Verification

The regression coverage exercises scoped image paths, sanitized diagnostics,
actual preparation checks, and delayed Claim responses through the rendered
monitor. CI runs the full suite and verifies production installations with
default and custom tools. CD publishes the exact CI tarballs through npm
Trusted Publishing. Native Windows execution was unavailable during local
validation; the reported Windows separator failure was reproduced with Windows
path semantics.

See [the release guide](../releases.md) for publication and recovery.
