# CCDD v2.0.1

공개 npm 배포를 위해 패키지 이름을 `@ccdd` 범위로 정리합니다. 세 패키지의 버전은 2.0.1로 맞춥니다.

| 이전 이름 | npm 이름 | 역할 |
| --- | --- | --- |
| `@lhj6102/ccdd` | `@ccdd/core` | Artifact·Critic·도구 정의 |
| `@lhj6102/ccdd-project` | `@ccdd/project` | 프로젝트 검증·CLI·Broker·Executors·모니터 |
| `@lhj6102/ccdd-default-tools` | `@ccdd/default-tools` | 선택적으로 등록하는 기본 관측 도구 |

CLI 이름은 `ccdd-project`와 `ccdd`를 유지합니다. Project와 기본 도구는 `@ccdd/core >=2.0.0 <3`를 peer dependency로 사용합니다.

## 이전

새 버전이 게시된 후 세 패키지를 같은 버전으로 설치하고 원본 프로젝트의 `ccdd.config.ts`와 사용자 도구의 import를 새 이름으로 바꿉니다.

```sh
npm install --ignore-scripts @ccdd/core@2.0.1 @ccdd/project@2.0.1 @ccdd/default-tools@2.0.1
npx ccdd-project config check
npx ccdd-project tools check
```

이미 저장된 리뷰 snapshot과 데모는 이전 이름의 패키지·설정을 유지합니다. 새 데모는 새 이름을 사용하며 기존 데모를 다시 준비해도 내부 설정이나 의존성을 자동 교체하지 않습니다. 과거 GitHub Release 파일과 릴리스 노트는 당시 이름을 유지합니다.

## 배포와 검증

`release:npm`은 지정한 커밋의 임시 clone에서 전체 빌드·테스트, 실제 패키지 설치·도구 실행·Runtime·검증 재사용을 확인한 후 검증된 tarball을 게시합니다. `--dry-run`은 실제 게시 없이 같은 패키지를 검사합니다. 배포 실패 후에는 같은 바이트로 게시된 패키지만 건너뛰고 재시도할 수 있습니다.

절차와 npm 조직 권한 확인은 [배포 안내](../releases.md#npm-공개-배포)를 참고하세요. 이 문서의 존재는 npm이나 GitHub 게시 완료를 의미하지 않습니다.
