# CCDD v3.1.0

CCDD 3.1.0 adds Node.js 22 LTS support and licenses CCDD under MIT. All three
packages release together: `@ccdd/core`, `@ccdd/project`, and
`@ccdd/default-tools`.

## Changes

- Support Node.js 22 LTS starting at 22.19.0, alongside Node.js 24 and later.
  The Pi dependencies determine the Node 22 minimum. Earlier Node 22 releases,
  Node 20, and Node 23 remain unsupported.
- Share the runtime requirement across Runtime readiness checks and release
  tooling, and compile against Node 22 type definitions.
- Select Node 22 through `.nvmrc` and verify the minimum Node 22 version,
  latest Node 22, and Node 24 in CI.
- Include the complete MIT license and SPDX license metadata in every package.
- Preserve the Node requirement of the verified package when recovering an
  older GitHub release announcement.

## Install and upgrade

```sh
npm install --ignore-scripts @ccdd/core@3.1.0 @ccdd/project@3.1.0 @ccdd/default-tools@3.1.0
npx ccdd-project config check
```

The default-tools package is optional for projects using only custom tools.
Use the latest patch of a supported Node LTS release. Existing 3.x
configuration and review state remain compatible; restart an active monitor
with the updated CLI. Existing reviews retain their captured implementations.

## Verification

CI runs type checks, the complete Node test suite, and production package
installation checks on Node 22.19.0, latest Node 22, and Node 24. Local release
verification builds the selected committed snapshot and checks actual default
and custom tool execution, Runtime review, and verdict reuse from its tarballs.
These checks do not call an external AI Provider or launch desktop applications.

See [the release guide](../releases.md) for publication and recovery, and
[getting started](../getting-started.md) for a complete Runtime example.
