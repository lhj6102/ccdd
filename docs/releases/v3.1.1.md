# CCDD v3.1.1

CCDD 3.1.1 updates the npm documentation and publishes packages from verified
CI artifacts. All three packages release together: `@ccdd/core`,
`@ccdd/project`, and `@ccdd/default-tools`.

## Changes

- Replace the main README's Mermaid overview with an image showing Creative
  Critic Driven Development, separate Critic relationships, customizable
  Artifact types and tools, and Pi-based Agent reviewers.
- Keep seam coverage while removing redundant helper and retired publication
  tests. Seed monitor history fixtures in one SQLite transaction.
- Run tests and production package checks once in main CI. Version-tag CD
  publishes the matching CI artifacts without rebuilding or rerunning tests.

## Install and upgrade

```sh
npm install --ignore-scripts @ccdd/core@3.1.1 @ccdd/project@3.1.1 @ccdd/default-tools@3.1.1
```

Node.js 22 LTS (22.19.0 or later) and the MIT license remain unchanged.
The default-tools package is optional when all tools are custom. Existing
3.x configurations and review state remain compatible.

## Verification

CI runs the 326-test seam suite and verifies actual default/custom tool
execution, Runtime review, and verdict reuse from production installations.
CD checks the source commit and package integrity before publishing those
exact tarballs through npm Trusted Publishing.

See [the release guide](../releases.md) for publication and recovery.
