# v0.9.0 verification record

2026-09-06 · macOS · Node 24.15.0.

## Packaging and reproduction

- Core and default-tools were packaged as separate actual npm tarballs and installed in a separate project without development dependencies. TS configuration and default tools ran without TypeScript or Vite.
- After a copy was created, Agent read/list tools and the Human launcher remained executable from the copy even after the original project was moved away from its original path. The launcher in this check was a test Node process that recorded the path.
- A handwritten custom Reader also ran in a core-only project without the default tool library.
- The new demo-v9 installed dependencies once from local tarballs and copied them as actual files into four projects. Each project was checked with `--copy` for TS imports, preflight of 10 tools, and execution of Agent read/list tools.

## Automated verification coverage

`npm run build` passed, and all 236 tests passed with `node --test --test-concurrency=4 dist/test/*.test.js`. Key regression coverage included:

- Separation of TS configuration evaluation and execution, graph/envelope generation from a single configuration evaluation, and closure isolation per review.
- Rejection of imports outside the snapshot, manifest or Critic scope mismatches, JSON/TS conflicts, and empty audience tool lists.
- Rejection of invalid schemas, arguments, and results; validation of image output paths, MIME types, and sizes.
- Delivery of arbitrary tools and image content through the actual Pi Agent loop and MCP; rejection of models without image support and missing required observations.
- Prevention of passing when observation persistence fails; preservation of arbitrary operations, observation kinds, and descriptions in completion results and events.
- Cancellation, timeouts, abnormal host termination, and descendant process cleanup.
- No user code execution on monitor GET requests; Human claims, CSRF, retries after errors, missing original sources, restarts, and verdict persistence.
- Preservation of existing JSON, copy/lock, Artifact DAG, Runtime, and demo behavior.

Automated Agent tests connect a test transport to the actual Pi tool loop; these are distinct from the actual Provider verification in the table above. Verification did not cover renderers for specific animation/VFX engines, desktop integrations outside macOS, or public npm publication.
