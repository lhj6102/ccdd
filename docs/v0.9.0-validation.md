# v0.9.0 검증 기록

2026-09-06 · macOS · Node 24.15.0.

## 패키지와 재현

- Core와 default-tools를 각각 실제 npm tarball로 만들고 개발 의존성 없이 별도 프로젝트에 설치했다. TypeScript·Vite 없이 TS 설정과 기본 도구를 실행했다.
- 복사본을 만든 뒤 원본 프로젝트 경로를 사용할 수 없도록 옮겨도 복사본의 Agent 읽기·목록과 Human launcher를 실행할 수 있었다. 이 단계의 launcher는 경로를 기록하는 테스트용 Node 프로세스였다.
- 기본 도구 라이브러리가 없는 core-only 프로젝트에서도 직접 작성한 custom Reader를 실행했다.
- 새 demo-v9는 로컬 tarball에서 의존성을 한 번 설치하고 네 프로젝트에 실제 파일로 복사했다. 각 프로젝트의 `--copy`에서 TS import와 도구 10개의 preflight 및 Agent 읽기·목록 실행을 확인했다.

## 실제 실행

| 검증 | 관찰 |
| --- | --- |
| Provider doctor | `openai-codex / gpt-6-astra / medium`에서 실제 nonce 도구 왕복이 READY였다. 프로젝트 도구는 preflight만 수행했다. |
| 실제 Agent | 사용자가 전송을 승인한 생성 샘플 `why.md`·`spec.md`만 `read_why`·`read_spec`으로 관측했다. 수치·정렬·원본 불변 조건에 관한 파일/줄 근거와 함께 GREEN을 반환했다. |
| Runtime | 실제 Node 테스트 종료 코드는 baseline 0, why-change 0, runtime-failure 1, fixed 0이었다. Why의 의미 불일치를 Runtime 결과로 추론하지 않았다. |
| Human desktop | 모니터에서 claim한 개발용 요청의 `open_spec`을 실행했다. TextEdit에 복사본의 `spec.md`가 잠긴 문서로 열렸고 제목·본문을 실제 읽었다. |
| Human custom input | 숫자 `0.75`, boolean `true`, enum `depth`가 문자열이나 정수로 잘못 변환되지 않고 반환되었다. |
| Human completion | 확인한 내용으로 요약·근거를 작성해 제출했고, 모니터에서 저장된 GREEN과 근거 2개를 확인했다. 프로그램 열기 자체는 판정을 제출하지 않았다. |

실제 Agent Run은 `2e331128-9ab9-416a-83ac-117790c4d17e`, Human 개발 검증 Run은 `907c46d6-6adf-43ab-8322-6d723edf7dd1`이다. 로컬 상태·인증 파일·Provider 원문 로그는 커밋하지 않는다. Agent 결과를 점검하며 발견한 custom 관측 메타데이터 저장 누락은 이후 수정하고 Broker 완료·재시작 회귀 테스트로 검증했다. 기존 Run 기록은 수정하지 않았다.

## 자동 검증 범위

`npm run build`가 통과했으며, `node --test --test-concurrency=4 dist/test/*.test.js`에서 236개 테스트가 모두 통과했다. 주요 회귀 범위는 다음과 같다.

- TS 설정 평가와 실행 분리, 한 번 평가한 설정으로 graph·envelope 생성, 리뷰별 closure 격리
- snapshot 밖 import와 명세·Critic 범위 불일치 거부, JSON/TS 충돌과 빈 audience 도구 거부
- 잘못된 schema·인자·결과 거부, 이미지 출력 경로·MIME·크기 검증
- 실제 Pi Agent 루프와 MCP에 임의 도구·이미지 콘텐츠 전달, 이미지 미지원 모델과 필수 관측 누락 거부
- 관측 저장 실패로 통과할 수 없음, 임의 operation·관측 종류·설명이 완료 결과와 이벤트에 보존됨
- 취소·시간 제한·호스트 비정상 종료·하위 프로세스 정리
- 모니터 GET에서 사용자 코드 실행 없음, Human claim·CSRF·오류 후 재시도·원본 부재·재시작·판정 저장
- 기존 JSON, copy/lock, Artifact DAG, Runtime 및 데모 보존

자동 Agent 테스트는 Pi의 실제 도구 루프에 테스트용 전송기를 연결한다. 위 표의 실제 Provider 검증과 구분한다. 특정 애니메이션/VFX 엔진의 렌더러, macOS 외의 데스크톱 연결, npm 공개 게시까지 검증한 것은 아니다.
